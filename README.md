# YZ Tool V6 - Premium 🚀

A powerful, browser-based video processing tool designed to bypass compression algorithms and maintain full 60fps quality for TikTok uploads.

## ✨ Features
- **YZ Method 60 fps**: Forces and strictly maintains 60fps output to prevent quality loss.
- **Ultra Smooth Frame**: Advanced frame interpolation logic for smoother playback.
- **100% Client-Side Processing**: Powered by `FFmpeg.wasm`. All video processing happens entirely in your local browser. No server uploads, ensuring complete privacy.

## ⚠️ Important Usage Notes
- **Browser**: Use strictly on **Google Chrome** for optimal performance.
- **TikTok Web Upload**: Do **NOT** use the "Add Song" feature when uploading via TikTok web, as it will degrade the video quality. 
- **VPN Recommendation**: Use a VPN (Japan, Germany, or UK) when uploading for maximum 1080p resolution.
- **Credits**: Please include `#yztool` in your captions.
